# M5: 视觉分段对接 - 任务清单

> 目标：实现从预备点到充电桩的精细对接，初期使用理想位姿模拟视觉伺服。

- [ ] **M5.1** 实现 `DockActionNode` 结构
  - 先导航到 `dock_prep_pose`（可复用 NavigateToPoseNode）
  - 然后调用视觉伺服节点
- [ ] **M5.2** 实现模拟视觉伺服 `VisualServoNode`
  - 从 `/gazebo/model_states` 获取充电桩与机器人真实相对位姿
  - 实现 P 控制器输出 `cmd_vel` 进行对准
  - 成功条件：角度偏差 < 0.05 rad，横向偏差 < 0.02 m
  - 超时 15 秒
- [ ] **M5.3** 添加对接重试机制
  - 用 `RetryNode` 包裹视觉伺服节点，最多重试 3 次
  - 失败时记录报警，并返回 FAILURE
- [ ] **M5.4** 模拟充电完成
  - 视觉对接成功后，等待 10 秒（模拟充电）并将电量设为满
- [ ] **M5.5** 测试完整对接流程
  - 从低电触发到对接成功并满电恢复巡逻
