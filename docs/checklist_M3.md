# M3: 巡逻序列实现 - 任务清单

> 目标：加载预定义巡逻点，使用行为树逐个导航，实现基本巡逻循环。

- [ ] **M3.1** 配置巡逻点
  - 编写 `waypoints.yaml`，包含至少 3 个巡逻点、充电预备点、充电桩坐标
- [ ] **M3.2** 实现 `LoadWaypointsNode`
  - 从 YAML 文件读取所有位姿，写入行为树黑板
- [ ] **M3.3** 实现 `NavigateToPoseNode` 行为树节点
  - 封装 `navigate_to_pose` 动作客户端
  - 支持超时端口，返回成功/超时/失败
- [ ] **M3.4** 编写 `patrol_round.xml` 子树
  - 遍历 `waypoints`，逐个调用 `NavigateToPoseNode`
  - 到达每个点后短暂停留（延时节点）
- [ ] **M3.5** 实现堵赛放弃逻辑
  - 导航超时后使用 Fallback 返回 FAILURE
  - 黑板记录失败事件，继续下一个巡逻点
- [ ] **M3.6** 集成至主行为树，测试巡逻序列
  - 手动启动，观察机器人依次访问所有点并处理障碍
