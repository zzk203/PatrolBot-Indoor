# M4: 电池模拟与低电回充 - 任务清单

> 目标：模拟电池状态，实现低电自动中断并返回充电桩。

- [x] **M4.1** 实现 `BatterySimulatorNode`
  - 发布 `sensor_msgs/BatteryState` 话题
  - 参数化放电速率（巡航时）和充电速率
  - 初始电量 100%，随时间递减
- [x] **M4.2** 实现 `BatteryMonitorNode` 行为树条件节点
  - 订阅电池话题，判断是否低于阈值（如 20%）
  - 输出结果写入黑板或直接返回 SUCCESS/FAILURE
- [x] **M4.3** 实现低电中断逻辑
  - 在主行为树中插入 `ReactiveSequence` 检查电量
  - 低电时设置中断标志，中止当前导航动作
- [x] **M4.4** 实现 `ChargeRecovery` 子树（先仅导航回 dock）
  - 导航到 `dock_prep_pose`（充电预备点）
  - 使用定时器模拟充电过程（等待 10 秒后恢复满电）
- [x] **M4.5** 恢复巡逻逻辑
  - 充电结束后，从黑板断点索引继续巡逻
- [x] **M4.6** 完整测试低电回充流程
  - 人为降低电池阈值，观察机器人回充并恢复巡逻
